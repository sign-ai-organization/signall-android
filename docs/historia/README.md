# Historia

Documentos que **ya cumplieron su función**: planes de una semana, reportes de una
auditoría cerrada, contrastes contra documentos de una fecha concreta. No se editan y no
describen el presente.

Están acá y no borrados a propósito: el SRS, el SDD y la memoria citan varios de ellos, y
un archivo marcado como historia no se vuelve a leer por error en una sesión de trabajo.

| Documento | Qué fue |
|---|---|
| `PLAN-SEMANA-13.md` | Plan de la semana del 13, cerrado |
| `PENDIENTES-AUDITORIA-2026-10-24.md` | Pendientes que salieron de la auditoría del 2026-10-24 |
| `REVISION-DEVELOP.md` | Revisión de la rama `develop`, que ya no existe |
| `CONTRASTE-APPvsDOCUMENTOS.md` | Contraste de la app contra los documentos, de una sesión concreta |
| `CONTRASTE-BACKEND-ARTIFACT-2026-11-03.md` | Contraste del backend contra el `artifact`, del 2026-11-03 |
| `REPORTE-2026-11-03-spec-ui-y-srs.md` | Reporte de alineación entre el spec de UI y el SRS |
| `PREPARACION-AJUSTES-ANIMACIONES.md` | Preparación de una tanda de ajustes de animación, ya aplicada |
| `ramas-y-historial-2026-11.md` | Ramas que ya no existen y la reescritura del historial del 2026-11-14, con el mapeo de hashes |
| `plan-pruebas/` | Los reportes de las rondas de prueba y los planes que las ordenaron |
